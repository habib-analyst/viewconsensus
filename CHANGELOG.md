# Changelog

## 0.1.0 - 2026-10-28

- Initial release of ViewConsensus.
- Eight-view consensus panel for PyTorch tensors, NumPy arrays, and PIL images.
- Consensus probabilities, winning-class spread, agreement, per-view votes, and a defer-to-human verdict.
- Held-out threshold fitting for deferral policies.
- Framework-agnostic aggregation from per-view probability matrices.
